Complete v1 scope
- Browser access and video playback; desktop remote connections; saved multiple servers and explicit active-host targeting; local server plus remote windows; client-only native startup without importing database/torrent services; headless hosting and local recovery.
- One authoritative library/database/torrent engine per server, stable persisted server ID independent of routes. Files and downloads remain on host. No implicit library merging or cross-server mutations.
- Same-origin remote UI served by selected host in an isolated WebView, while native-owned connection management remains available offline. No general native bridge capability for remote content. Preserve the shared isomorphic Eden client.
- Settings/Connections host exposure, hostname/port/interfaces, HTTPS, local certificate trust onboarding, Tailscale private HTTPS integration, externally configured domain/reverse proxy support, desktop discovery and manual URL fallback, pairing link/QR and short code.
- Be honest that arbitrary browsers cannot automatically trust a self-signed LAN certificate; no insecure fallback or promise of zero-setup trust. TLS validates the endpoint; a public server UUID alone is not authentication. Discovery addresses are hints, not trust. IPv4/IPv6, interface changes, changing LAN IPs, guest network isolation handled.
- One-time expiring pairing grant atomically consumed into a durable per-device session. Invitation secret in URL fragment and removed from history. Session expiration/renewal, native secure credential storage, HttpOnly/Secure browser cookies, rate limiting and origin/CSRF defenses. Session revocation must terminate active streams/read waits. Local host or CLI can recover access.
- Read, Manage, Admin presets; file deletion explicit capability. Read includes own playback progress. Server-side checks on every relevant operation; protected HTML SSR, /_furin/data, deferred reads, sync and SSE, file HEAD/GET/Range/content routes, not only visible API buttons. Session-scoped mutation idempotency/cache provenance; safe library read shape distinct from admin/private data.
- Connection runtime with single retry owner, jittered backoff, network/foreground wakeups, distinguish offline/auth/configuration/incompatibility. Fresh state after reconnect, old generations cannot overwrite new state. No blind replay of mutations. Preserve saved hosts when offline. Route failover must preserve host identity and confidentiality; avoid disrupting healthy playback for an arguably faster route.
- Capability/protocol negotiation; meaningful compatibility/update guidance. Explicit forget/disconnect vs stop-host semantics. Host downloads continue when clients disconnect. Backup restoration vs cloned new identity explicitly distinguished.
- Video Range/HEAD/416 correctness, finished and in-progress torrents, audio/subtitle selection, seek/resume, per-device playback state with possible shared playback profile, bounded concurrent readers/memory/waits/cancellation/fairness, storage disappearance and paused/incomplete torrents. External-player access limited to a file and revocable. No universal device/codec compatibility claims without validation.
- Native operations must target correct device: current runtime.kind === desktop describes server, not caller. Folder pickers/reveal/open external/updates/openings need local-vs-remote capability handling. Host credentials remain host-owned. AniList OAuth needs remote-compatible flow; guest playback must not implicitly modify owner's AniList progress. Separate per-client UI preferences from host settings.
- Tests through real typed Eden endpoints and real application processes, peer transfers in temp dirs; no function unit tests or snapshots in Tofu. Security cases, revocation during streaming, reconnect idempotency, SSR leaks, local/remote coexistence, upgrades and startup failures are release gates.
- Feature off by default; validated configuration before activation; preserve prior valid settings on failed activation; no silent plain-HTTP downgrade. Diagnostics redact credentials and pairing links. Document platform/browser matrix and deployment/recovery flows.

Explicit later extensions
Managed Tofu cloud relay/account service, automatic SSH provisioning/installation/lifecycle, server-side transcoding, Cast/TV applications, automatic library merging/moving media across hosts. An externally managed SSH tunnel can be treated as a route but native SSH automation is not required v1.
