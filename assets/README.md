# Icône Tofu

`tofu-icon.png` est le logo retenu : un fichier assemblé en pièces, relié à trois pairs, dans les tons olive et ivoire. Il a été généré avec l’outil imagegen intégré ; le prompt est conservé dans [tofu-swarm-proposal.md](tofu-swarm-proposal.md).

`tofu.iconset/` contient ses dix tailles macOS, exportées avec `sips`. Electrobun convertit cet iconset en `AppIcon.icns` au build via `build.mac.icons`.
